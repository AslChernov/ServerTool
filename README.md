# ServerTool

Интерактивная пост-настройка и защита Ubuntu/Debian-ноды Remnawave. Скрипт рассчитан на запуск **после установки ноды**.

## Что умеет

- обновляет систему;
- настраивает UFW с политикой `deny incoming` / `allow outgoing`;
- открывает `443/tcp`, `443/udp` или оба протокола на выбор;
- разрешает API-порт ноды (по умолчанию `2222/tcp`) только с IPv4/CIDR панели;
- добавляет публичный SSH-ключ или генерирует Ed25519-пару;
- переводит SSH на случайный или указанный порт и проверяет конфигурацию до перезапуска;
- устанавливает отдельную nftables-защиту для обычного и Docker-трафика;
- обновляет Anti-Scanner-списки по systemd-таймеру и умеет добавлять Geo-block;
- устанавливает XanMod LTS или Main из официального репозитория с автоматическим выбором x86-64-v2/v3;
- делает резервные копии firewall и SSH-конфигурации.

TrafficGuard, CrowdSec и сторонние «ускорители» не устанавливаются. Скрипт не выполняет `nft flush ruleset`: он управляет только своей таблицей `inet server_tool_guard`.

## Запуск

```bash
sudo apt-get update && sudo apt-get install -y curl
curl -fsSL https://raw.githubusercontent.com/AslChernov/ServerTool/main/server_tool.sh -o server_tool.sh
chmod +x server_tool.sh
sudo ./server_tool.sh
```

Для просмотра состояния без меню:

```bash
sudo ./server_tool.sh --status
```

## Рекомендуемый порядок

1. Запустите полную настройку или сначала добавьте SSH-ключ.
2. Настройте новый SSH-порт.
3. Не закрывая текущую сессию, проверьте вход в новом окне.
4. Настройте UFW: выберите протоколы для `443`, порт ноды и IP панели.
5. При желании установите XanMod и затем перезагрузите сервер.

## Важные замечания

- По умолчанию API ноды доступен только с `45.148.62.18`; в меню это значение можно заменить.
- UFW работает только с IPv4 (`IPV6=no`) согласно сценарию для ноды.
- nftables-таблица дополнительно закрывает порт ноды в цепочках `input` и `forward`, включая проверку исходного порта до Docker DNAT. Это защищает Docker-публикации, которые не всегда ограничиваются обычным правилом UFW.
- Geo-block по умолчанию выключен. Коды стран задаются отдельно в меню nftables.
- Приватный ключ, созданный на сервере, нужно безопасно скачать, проверить и удалить с сервера.
- Скрипт не перезагружает сервер автоматически.

## Файлы на сервере

| Назначение | Путь |
|---|---|
| Настройки защиты | `/etc/server-tool/guard.conf` |
| Обновление списков | `/usr/local/sbin/server-tool-guard-update` |
| SSH-настройки | `/etc/ssh/sshd_config.d/00-server-tool.conf` |
| Резервные копии | `/var/backups/server-tool/` |
| Лог | `/var/log/server-tool.log` |

## Поддержка

- Ubuntu и Debian;
- архитектура amd64 обязательна только для XanMod;
- запуск от `root`/через `sudo`.

Перед применением на рабочей ноде полезно сделать snapshot в панели хостинга и держать открытой резервную консоль.

Актуальные команды XanMod сверяются с [официальной страницей проекта](https://xanmod.org/). Настройка SSH основана на [документации Ubuntu Server](https://documentation.ubuntu.com/server/how-to/security/openssh-server/).
